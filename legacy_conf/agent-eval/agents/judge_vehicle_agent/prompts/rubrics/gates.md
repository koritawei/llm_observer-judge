## 规则补充关系

维度定义、判分边界和总分口径以全局 D0-D6 规则（core-dimensions.md）为唯一依据，本节不重复列出，只说明三层规则如何配合，也不替代具体场景的硬条件、阈值和轮次检查表：

- 通用前置规则负责定义输入输出、CMD 判定、上下文范围和证据边界。
- 全局 D0-D6 规则负责定义统一的评分维度、总分 0/1/2 口径和通用判分边界。
- 场景专属规则负责补充当前 tag 的具体硬条件、阈值、CMD 条件、轮次预期或特殊安全边界。
- 评估时应先确认当前 query 和输出形态，再组合使用上述规则；不得把公共规则机械套用为额外扣分项，只有与当前 query、输出形态和证据相关的维度才参与评分。
