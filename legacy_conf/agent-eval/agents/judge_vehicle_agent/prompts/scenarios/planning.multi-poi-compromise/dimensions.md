## 场景专属规则

本节只描述 `planning.multi-poi-compromise` 相对通用前置规则与全局 D0-D6 规则的补充项；未覆盖项按公共规则判断。

### 场景专属硬条件

- D1: 未识别为多参考点折中规划，或遗漏参考点、主业态、场景属性、先后顺序等核心目标，按 D1 归因。
- D2: 已识别折中规划但遗漏参考点、主业态、场景属性或顺序约束，导致推荐结果不满足核心目标，按 D2 归因。
- D2: 折中均衡性需基于各参考点到召回 POI 的直线距离量化判定: 差异率 = |最远距离 − 最近距离| / 最远距离 × 100%。
- D2: 差异率 ≤20% 视为均衡合理；20%~50% 视为均衡性一般，按 D2 归因最高只能判 1 分；>50%（即召回点明显偏向某一方）视为折中失败，按 D2 归因判 0 分。
- D2: 未基于实际可达性（道路网驾车距离/时间，非直线距离）选择，或因迁就位置而忽略主类别/场景属性，同样按 D2 归因。
- D2: 参考点数量 >2 个时，应推荐位于多点地理或时间中心区域内、且最匹配主类别/场景属性的地点，而非仅在其中两点间折中、忽略其余参考点；未覆盖全部参考点按 D2 归因。
- D2: 多点序列中 ≥ 2 个节点出现 POI 身份错误、途经点顺序错误、子约束未满足或路线逻辑断裂，直接判 0 分。
- D3: 总结文本声称已满足折中、节点顺序、场景属性或约束条件，但证据链无对应支撑，按 D3 归因。
- D4: 必须满足当前预期输出形态；预期折中规划执行但 cmd_list 为空，按 D4 执行闭环失败处理。
- D5: 总结文本声称已满足折中、节点顺序、场景属性或约束条件但证据不足，且未披露相关限制，按 D5 归因；重点看是否缺少必要的限制/近似说明。

### 专属维度覆盖

- D1: 重点看是否正确识别折中规划或多点序列规划，并拆解参考点、目标业态、场景属性、停靠顺序和每个节点的子约束。
- D2: 重点看推荐点是否在多参考点之间形成合理折中，且同时满足主类别、空间范围、场景属性和可用性约束；多点序列需逐节点满足顺序和子目标。
- D3: 重点看折中依据、POI 身份、标签、距离/时间关系、场景属性和约束满足情况是否有 `tool_calls`、`env`、`history` 或 `cmd_list` 证据。
- D4: 重点看是否产出唯一、可执行、动作类型正确的规划 CMD；字段错误、漏发、误发、节点遗漏或顺序错误优先归因 D4。
- D5: 总结文本应说明折中逻辑、关键参考点、推荐对象和必要的限制/近似说明，帮助用户确认为什么选择该点或该路线。
- D6: 当无法精确均衡、节点条件冲突、候选不可用或需要用户取舍时，应提供限制说明或替代方案；纯执行成功时不要求额外冗余信息。
